## Lessons Learned

1. **ก่อนย้าย model files ต้อง stop ComfyUI ก่อนเสมอ** — ไฟล์ที่กำลัง load อยู่จะ corrupt ถ้า mv ขณะรัน
2. **ComfyUI "Missing" มักเกิดจาก workflow reference ชื่อไม่ตรง ไม่ใช่ไฟล์หาย** — ต้องดู node name และเปรียบกับ ls models/ ก่อนโหลดเพิ่ม
3. **Large files (models, datasets) ควรเก็บใน /mnt/data เสมอ** — main drive สำหรับ OS + code เท่านั้น
4. **Loki-Gemini ใช้ได้แค่ text tasks ใน no sandbox mode** — งาน bash/file ops ต้องทำโดยตรงใน Claude
