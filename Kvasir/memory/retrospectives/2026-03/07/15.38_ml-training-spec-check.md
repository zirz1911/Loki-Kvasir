## Honest Feedback

Three friction points this session:

1. **PowerShell in bash context is painful.** The `$variable` interpolation conflict between bash and PowerShell means every multi-line script has to be broken apart. This is a recurring tax on Windows work. Would benefit from a wrapper script or always using `-File` with a temp `.ps1` file instead of `-Command`.

2. **Remote divergence without warning.** The push failed because remote had new commits. This happens often enough that `git pull --rebase` should almost be a default step before any push. The workflow could be smoother with a pre-push check baked in.

3. **WMI VRAM reporting is inaccurate for NVIDIA.** `Win32_VideoController.AdapterRAM` reported ~4GB when the actual VRAM is 6GB. Always need `nvidia-smi` to get truth. Good that I followed up — but it's a silent accuracy issue that could mislead.

## Lessons Learned

- RTX 4050 Laptop (6GB VRAM) can handle QLoRA fine-tuning of 7B models with 4-bit quantization
- On Windows via bash shell, PowerShell multi-line scripts with `$vars` get their `$` stripped — use separate `-Command` one-liners instead
- `Win32_VideoController.AdapterRAM` is unreliable for NVIDIA — always verify with `nvidia-smi`
- Unsloth is the best starting point for memory-constrained GPU fine-tuning
