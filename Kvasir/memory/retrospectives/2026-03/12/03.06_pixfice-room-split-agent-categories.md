## Lessons Learned

1. **อ่าน source of truth ก่อน design** — ถ้ามีเอกสารที่ define categories/roles อยู่แล้ว (README, CLAUDE.md) ให้อ่านก่อน ไม่ใช่ guess จาก convention แล้วค่อย refactor ทีหลัง

2. **HTML components ไม่ render ใน SVG context** — `<AgentAvatar>` (div+box-shadow) ใน `<svg>` = invisible ทุกครั้ง ถ้าจะ embed HTML ใน SVG ต้องใช้ `<foreignObject>` หรือ unwrap SVG แล้วใช้ div แทน

3. **Single source of truth ใน constants.ts ทำให้ change propagates ทุก view** — `agentCategory()` function เดียว ทำให้เพิ่ม/เปลี่ยน category แก้ที่เดียว Fleet/Office/Overview/Mission อัปเดตพร้อมกัน

4. **Virtual sessions เป็น pattern ที่ดีสำหรับ UI grouping ที่ไม่ตรงกับ tmux structure** — แทนที่จะเปลี่ยน tmux setup ให้มีหลาย sessions, สร้าง virtual session objects ใน useMemo แล้ว pass ไป component เดิมได้เลย

5. **dist-office ถูก gitignore — ต้อง rebuild ทุกครั้งที่ deploy** — ไม่ควรเชื่อว่า dist ที่ server serve อยู่คือ latest source เสมอ
