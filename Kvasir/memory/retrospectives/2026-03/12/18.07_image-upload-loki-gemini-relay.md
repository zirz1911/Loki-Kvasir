## Honest Feedback

**Friction 1**: Gemini CLI shell mode — `!` ที่ต้น string trigger shell mode ทันที แต่ตอนนั้น Lokkji ทักมาว่า "สวัสดี!" ซึ่งขึ้นต้นด้วย "สวัสดี" ไม่ใช่ `!` — แต่ string ที่ส่งไป tmux จริงๆ คือ `"สวัสดี! ฉัน..."` ซึ่งมี `!` อยู่ใน Thai text. ฉันเสียเวลาหลายรอบก่อนจะเห็น pattern นี้

**Friction 2**: tmux Bash tool reset cwd — ทุกครั้งที่ run Bash tool ใหม่ cwd reset กลับมาที่ `/home/paji/Loki-Kvasir` แม้จะ `cd` ไปที่อื่นในคำสั่งก่อนหน้า. ต้อง prefix ทุก command ด้วย `cd /project && cmd` ซึ่งทำให้ command ยาวและบางครั้งลืม

## Lessons Learned

1. **Gemini CLI special keys**: `!` ที่ต้น input = shell mode, Ctrl+R = history reverse search. ก่อนส่ง message ผ่าน tmux ให้ใช้ `C-u` clear input ก่อนเสมอ เพื่อ avoid side effects
2. **SSH terminal cannot handle binary**: Terminal protocols เป็น text-based — image paste ผ่าน PowerShell/CMD/SSH ไม่ใช่ seamless path. Web UI เป็น only practical option สำหรับ binary data
3. **Browser paste API**: `ClipboardEvent.clipboardData.items` ทำงานบน desktop browsers แต่ mobile (iOS Safari) อาจไม่ include image blob — upload button เป็น reliable fallback
4. **Auto-commit hooks ใน Loki-Pixfice**: มี hook ที่ commit + push อัตโนมัติหลัง file edit. Commit message อาจไม่ตรงกับ intent จริง — ควร verify message หลัง hook run
