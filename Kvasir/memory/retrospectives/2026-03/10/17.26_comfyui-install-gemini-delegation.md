## Honest Feedback

**Friction 1**: vae symlink ล้มเหลวเพราะไม่ verify สิทธิ์ก่อน symlink ทุกตัว ควร `touch test && rm test` ก่อนเสมอ
**Friction 2**: wget background jobs (&) ใช้ relative path fail — ต้องใช้ absolute path เสมอเมื่อ run background process
**Friction 3**: Delegate งาน bash ให้ Loki-Gemini (no sandbox) โดยไม่เช็ค capability ก่อน — เสียเวลารอ

---

## Lessons Learned

1. **Background jobs (&) ไม่ inherit cwd ของ parent shell เสมอ** — ใช้ absolute paths เสมอเมื่อ run parallel wget/curl ใน background
2. **ก่อน symlink folder ที่จะเขียน ต้อง verify write permission ก่อนเสมอ** — `touch /path/test && rm /path/test` เป็น one-liner ที่ควรใช้
3. **Loki-Gemini (no sandbox) ทำ system/bash commands ไม่ได้** — ใช้ได้แค่ text, code gen, research — งาน ops ยังต้องให้ Claude ทำเอง
4. **PyTorch + ComfyUI ต้องใช้ venv บน Ubuntu/Debian** — pip global install ถูกบล็อกโดย PEP 668 ทุกครั้ง
