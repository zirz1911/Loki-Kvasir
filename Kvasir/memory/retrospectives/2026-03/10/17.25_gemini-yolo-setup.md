## Lessons Learned

1. **สำหรับ "add X to existing script" tasks** — อ่าน script ก่อน, check tool availability, แล้วค่อย explore ถ้าต้องการ context เพิ่ม อย่า launch broad exploration agent ทันที
2. **`--yolo` ดีกว่า `--sandbox` สำหรับ local tmux** — sandbox ต้อง Docker overhead, yolo เหมาะกับ trusted local dev environment
3. **Gemini CLI ใน nvm path ต้องใช้ absolute path ใน tmux** — `~/.nvm/versions/node/v22.22.0/bin/gemini` แทน `gemini` เพราะ tmux window ไม่ source nvm shell function
