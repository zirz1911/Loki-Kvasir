## Lessons Learned

- **Tauri build outputs**: Tauri creates both .app bundle and .dmg installer - .app for direct execution, .dmg for user distribution
- **aarch64 architecture**: macOS builds on Apple Silicon produce ARM64-only binaries by default - need explicit config for universal or x86_64
- **Prerequisites matter**: Rust + Bun + Xcode CLI are all required for Tauri macOS builds - missing any one causes cryptic errors
- **Background builds**: Long compilations should use `run_in_background: true` to avoid blocking - check output periodically instead
- **Repo separation**: Related projects should be sibling directories, not nested, unless they're true submodules
