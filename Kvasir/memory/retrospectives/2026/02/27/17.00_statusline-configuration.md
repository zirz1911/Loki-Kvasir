## Lessons Learned

- **Check local .claude first**: Project-specific `.claude` directories can contain important scripts that aren't in global config
- **Statusline files location**: Loki-Kvasir keeps statusline implementation in `.claude/statusline.py` (committed to git) but configuration in global `~/.claude/settings.json`
- **Schema requirements**: Claude Code statusLine config requires both `type` (must be "command") and `command` (path to script) fields
- **Restart required**: Configuration changes to `~/.claude/settings.json` require Claude Code restart to take effect
- **Agent tracking architecture**: Statusline reads `/tmp/claude_subagent_active.txt` for live subagent display, suggesting a hook-based coordination system
