## Lessons Learned

**kvasirnet-outbound-data**: Skills ที่ส่งข้อมูลออกภายนอกควรมี warning ชัดเจนใน SKILL.md หรือถ้า skill นั้นส่ง POST ไป third-party server โดย default — ควรพิจารณาลบออกเลยแทนที่จะ document

**pm2-crash-loop-pattern**: pm2 restart 58+ รอบ + EADDRINUSE = crash loop ชัดๆ วิธีแก้คือ stop → kill port → start clean ไม่ใช่แค่ `pm2 restart`
