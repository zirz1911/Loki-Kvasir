## Honest Feedback

**1. Mosquitto config debugging ยาวเกินไป**
ใช้เวลา debug Mosquitto config 20+ นาที เพราะ tee / heredoc ไม่ทำงานกับ leading spaces, garbage characters, permission issues ทับซ้อนกัน วิธีที่ดีที่สุดคือเขียน temp file ด้วย Python แล้ว sudo cp — ควร jump ไปที่วิธีนี้เร็วกว่านี้แทนที่จะลอง tee ซ้ำหลายรอบ

**2. Multi-user refactor ควรเกิดหลัง validate v1 ก่อน**
เราเริ่ม refactor เป็น multi-user ก่อนที่ single-user version จะ stable 100% ทำให้มีช่วงที่ location-server ไม่รับ messages เพราะ env var ไม่ถูก pass ถูกต้องผ่าน pm2 ถ้า validate v1 ก่อน แล้วค่อย refactor จะ debug ง่ายกว่า

**3. Public IP assumption ผิดตั้งแต่ต้น**
ควรถามก่อนว่า server อยู่หลัง NAT มั้ย ก่อนที่จะเริ่ม configure Mosquitto ให้รับ public connections ประหยัดเวลา troubleshoot ได้หลายรอบ

## Lessons Learned

**owntracks-tls-off-1883**: OwnTracks บน iOS default เปิด TLS ต้องปิด manual ไม่งั้น connect port 1883 ไม่ได้ (plain MQTT)

**mosquitto-config-write-pattern**: เขียน Mosquitto config ที่สะอาดที่สุดด้วย `python3 -c "with open(...) as f: f.write(...)"` แล้ว sudo cp — หลีกเลี่ยง heredoc และ tee เพราะ leading spaces และ shell escaping ทำให้ parse error

**tailscale-before-public-ip**: ก่อน expose MQTT สู่ public ให้ถามว่าเครื่องอยู่หลัง NAT มั้ย (`ip addr` vs `curl ifconfig.me`) ถ้า IP ต่างกัน = NAT = ต้อง port forward ก่อน
