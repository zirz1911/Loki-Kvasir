## Lessons Learned

**When a fix "doesn't work" — check what data the server actually received before assuming code is wrong.** Logs + git history tell you if the problem is upstream (client not sending) or downstream (server not handling). In this case: zero Paji pings since 19:23 = OwnTracks not sending = app-side issue, not server.
