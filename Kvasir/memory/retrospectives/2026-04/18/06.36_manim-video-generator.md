## Honest Feedback

Three friction points worth naming:

1. **Font failure was predictable but undetected** — Manim's Thai text failure is a known issue on systems without `fonts-thai-tlwg` or `fonts-noto-cjk`. We should have run a quick font check before delegating a 782-line script that relied on Thai text rendering. The fix was straightforward but cost a full re-render cycle.

2. **Script output path inconsistency** — The script writes the final MP4 to `/home/paji/Loki-Kvasir/lab/` even though the source lives in `/Project/smart-route-video/`. This split is confusing. If someone clones the project repo later, the output won't be where the code is. Small thing, but the kind of small thing that creates friction when you come back to a project cold.

3. **No scene preview before full render** — A 1080p60 5-scene Manim render takes 5-10 minutes on CPU. Running even Scene 1 at 480p first would have caught the font issue before committing to the full render. The `-ql` flag exists for exactly this. Should build that habit into the workflow.

## Lessons Learned

**Manim Thai font check before writing Thai text** — Before using Thai in any Manim script, run `fc-list | grep -i thai` to verify fonts are installed. Manim uses Cairo/Pango for text rendering; missing fonts produce silent failures (boxes or empty). If fonts are absent: install `fonts-thai-tlwg` OR switch to English. Don't write the script first and discover this after a full render.
