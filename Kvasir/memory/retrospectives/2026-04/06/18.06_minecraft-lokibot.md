## Honest Feedback

**1. online-mode เป็น blocker ที่ไม่คาดคิด**
เปลี่ยน online-mode=false ทำให้ server เปิดรับ cracked account ทุกคน ไม่ใช่แค่ bot ถ้า server นี้ public จะเป็นปัญหา security จริงๆ ทางออกที่ดีกว่าคือใช้ Microsoft account สำหรับ bot แต่ต้องการ browser login ครั้งแรก ยังไม่ได้ทำ

**2. Bot ไม่รู้ว่าตัวเองอยู่ในโลกแบบไหน**
Claude brain ตัดสินใจจาก perception ที่ค่อนข้างจำกัด ไม่รู้ว่าข้างๆ มีอะไร มี block อะไร ควรเพิ่ม nearby blocks, entity info เข้า perception เพื่อให้ brain ตัดสินใจได้ฉลาดขึ้น ตอนนี้ bot "ตาบอด" ในระดับหนึ่ง

**3. House builder ทำ server lag**
/fill command หนักมาก ส่ง 16+ commands ถี่ๆ ทำ server freeze ชั่วคราว ควรลด house size หรือใช้ structure template แทน fill ทีละ command

## Lessons Learned

1. **mineflayer bot เข้า online server ต้องใช้ Microsoft auth** — offline mode ใช้ได้เฉพาะ online-mode=false
2. **pathfinder ใน creative mode ต้องเปิด `canFly = true` และ `allowFreeMotion = true`** — ไม่งั้น bot ติดอยู่บนพื้นผิว
3. **Bot memory ป้องกันประโยคซ้ำได้** — track last N messages แล้วส่งเข้า prompt ว่า "ห้ามพูดซ้ำ" พร้อม `temperature: 1.0`
4. **enforce-secure-profile=false จำเป็น** สำหรับ offline bot ไม่งั้น client filter message ออก
