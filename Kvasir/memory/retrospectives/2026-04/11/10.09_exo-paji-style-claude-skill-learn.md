## Lessons Learned

1. **อ่าน source ก่อน replicate aesthetic** — ชื่อไม่เชื่อถือได้ ต้องดู CSS/code จริง
2. **ถาม context ก่อน decline** — ambiguous request ควรถามก่อน ไม่ใช่ decline ทันที (แม้จะ decline แล้วถามก็ยังดีกว่าไม่ถามเลย)
3. **loki-kvasir:6 = ymir ไม่ใช่ Gemini** — smart route hook ใช้ index 6 ซึ่งเป็น ymir ตาม CLAUDE.md; Gemini จริงอยู่ที่ window 7 (loki-gemini)
