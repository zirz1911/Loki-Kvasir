These silent breaks are the most dangerous — they don't throw errors, they just show nothing.

## Honest Feedback

**Friction 1 — ghq not installed but assumed**: The /learn skill assumes ghq is available. When it wasn't, there was a brief stumble before falling back to direct git clone. The skill could do a `which ghq` check first and branch immediately rather than failing mid-operation.

**Friction 2 — Two emoji update passes**: The first emoji pass added the new emoji alongside 🌟 (e.g., `🌟🎭`) instead of replacing it. This required a second pass to fix. The user's intent was "replace 🌟" but the first interpretation was "add alongside." A clarifying question before the first update would have saved one full round of API calls to both GitHub and Forgejo.

**Friction 3 — PM2 path is non-standard**: `pm2` wasn't on PATH. Had to hunt through `/home/paji/.npm/_npx/...` to find it. This is a system configuration issue but it caused unnecessary friction during the Loki-Pixfice restart. The app's own scripts should handle this — either installing pm2 globally or using a local wrapper script that resolves the path automatically.

---

## Lessons Learned

When a project is renamed or moved, every script that references its directory by name must be updated. The silent failure mode (app runs but shows empty) is harder to diagnose than an explicit error.
