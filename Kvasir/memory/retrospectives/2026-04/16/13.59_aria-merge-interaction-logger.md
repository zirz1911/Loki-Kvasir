## Honest Feedback

**1. Debug loop ยาวเกินไปสำหรับ hook payload format**
ใช้เวลา ~30 นาทีกับการ guess ว่า payload มี `event` field หรือเปล่า ถ้าเริ่มด้วยการ capture stdin ตั้งแต่ต้น จะแก้ได้ใน 5 นาที pattern "assume then guess" vs "observe first" เป็นสิ่งที่ต้องฝึกใหม่

**2. Global vs project settings confusion**
เพิ่ม hook ใน global `~/.claude/settings.json` ก่อน แล้วค่อยพบว่า project มี `settings.local.json` ที่มี hooks ของตัวเอง ทำให้ duplicate entries เกิดขึ้น ควร check project settings ก่อนแก้ global เสมอ

**3. `/learn` ต้องการ credentials ที่ไม่ได้เตรียมไว้**
Forgejo repo ต้องการ auth ทั้ง SSH (port 22 block) และ HTTPS (no credentials in env) ต้องไปหา stored credentials ใน `~/.git-credentials` เอง ถ้า repo มี authentication ควรถามก่อน `/learn` แทนที่จะ fail แล้วค่อย debug

## Lessons Learned

1. **Claude Code hook payload**: ใช้ `hook_event_name` (ไม่ใช่ `event`) และมี `prompt` field โดยตรงใน `UserPromptSubmit` — ไม่ต้องอ่าน transcript
2. **settings.local.json overrides กับ global**: ทั้งคู่ fire — ต้องระวัง duplicate hooks; เพิ่มใน project settings เท่านั้นถ้า hook นั้นเป็น project-specific
3. **Debug hooks ด้วย stdin capture ก่อนเสมอ**: อย่า assume payload format — เพิ่ม capture script ชั่วคราวแล้วดูของจริง
