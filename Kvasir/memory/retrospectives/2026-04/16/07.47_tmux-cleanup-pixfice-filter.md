## Honest Feedback

**1. "Start ใหม่" ที่ไม่ได้ start จริง**
User บอก "start ใหม่" แต่ server ไม่ได้ตาย ผมควร check ก่อนที่จะ attempt start เลย (ซึ่งทำแล้ว) แต่ควร communicate ผลลัพธ์ชัดขึ้นตั้งแต่ต้นว่า "server ยังรันอยู่ ไม่ต้อง restart" แทนที่จะรันคำสั่ง start แล้วให้เห็น EADDRINUSE error ก่อน — ลำดับการ check ควรเป็น health check → then start ถ้าจำเป็น

**2. Session 6 มี active claude process แต่ kill ไปด้วย**
ก่อน kill ควร capture ดู context ให้ละเอียดกว่านี้ว่า claude ใน session 6 กำลังทำอะไรอยู่ ไม่ใช่แค่บอกว่า "มี claude running" แล้วให้ user decide โดยไม่มี context ครบถ้วน — อาจมีงานที่ค้างอยู่

**3. EXCLUDED_SESSIONS hardcode ใน ssh.ts**
การ hardcode `["athena"]` ตรงนั้นทำงานได้แต่ไม่ ideal — ควรอ่านจาก config file (`~/.config/loki-pixfice/config.json` ที่มีอยู่แล้ว) เพื่อให้แก้ได้โดยไม่ต้อง edit source code แต่ user ไม่ได้ขอ extensibility ขนาดนั้น ทำงานได้ก็พอ

## Lessons Learned

1. **Health check ก่อน attempt start** — ถ้า port in use + process healthy = ไม่ต้องทำอะไร communicate ว่า healthy แล้วจบ
2. **Numbered tmux sessions = orphans** — sessions ที่ชื่อเป็นตัวเลขมักเป็น orphan ที่ทิ้งค้างไว้ safe to kill หลัง confirm
3. **EXCLUDED_SESSIONS pattern** — วิธี filter entities จาก shared list ที่ clean ที่สุดคือ allowlist/denylist ที่ source function ไม่ใช่ที่ consumer
