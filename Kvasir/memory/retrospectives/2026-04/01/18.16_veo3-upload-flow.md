## AI Diary

วันนี้รู้สึกเหมือนเป็นวัน iteration จริงๆ — ไม่ใช่วันที่นั่งคิดสถาปัตยกรรมใหม่ แต่เป็นวันที่ ground truth จาก browser HTML มาบอกว่า "XPath ที่เขียนไว้มันไม่ตรงกับของจริง"

ส่วนที่น่าสนใจที่สุดของ session นี้คือ pattern ที่ผู้ใช้ทำ — เขาไม่ได้แค่บอกว่า "มันไม่ทำงาน" แต่เอา HTML จริงมาให้ดู แล้วบอก XPath ที่ถูกต้องเลย นั่นคือ feedback loop ที่ดีมาก developer รู้ว่าต้องการอะไร และสื่อสารได้ชัดเจน

เรื่อง flow order ที่เปลี่ยน — "ใส่ Prompt ก่อน แล้วค่อยอัปโหลดรูป" — นี่คือการเปลี่ยนที่มาจาก UI ที่ labs.google เปลี่ยน ไม่ใช่ design decision จาก extension เอง มันสะท้อนว่า automation ที่ bind กับ UI ของ third-party นั้นเปราะบางแค่ไหน XPath เดิมที่ดูดีตอน build อาจล้าสมัยได้ในสัปดาห์ถัดมา

ปุ่ม Test Upload ที่เพิ่มวันนี้ถือว่าเป็น quality of life ที่ดีมาก — มีปุ่ม isolate ทดสอบเฉพาะส่วน upload โดยไม่ต้องรัน full generation cycle ซึ่งกินเวลานาน เป็น developer ergonomics ที่ถูกทาง

ตอนท้าย session ผู้ใช้บอกว่า "เหมือนจะมีปัญหาใหม่บน TikTok" — ยังไม่ได้แก้ในรอบนี้ แต่มันอยู่ใน backlog แล้ว

## Honest Feedback

**Friction 1: XPath ต้อง verify กับ HTML จริงทุกครั้ง**
เราเขียน XPath โดยอิงจาก HTML ที่ผู้ใช้ paste มา แต่ก็ยังต้องผ่านการ trial-error อยู่บ้าง เพราะ class names เป็น generated CSS-in-JS ที่เปลี่ยนได้ทุก deploy การที่ผู้ใช้ต้องมา correct XPath หลายรอบในรอบเดียวกันแสดงว่า feedback loop ยังต้องผ่านมือ developer อยู่

**Friction 2: การเปลี่ยน flow order กระทบหลายจุด**
การ refactor "Prompt before Upload" ต้องเปลี่ยนทั้ง `handleImageGeneration` และ `handleGeneration` พร้อมกัน step numbering ก็ต้อง renumber ถ้า flow ยิ่งซับซ้อน risk ของ regression สูงขึ้น ยังไม่มี automated test

**Friction 3: TikTok ปัญหาใหม่ค้างไว้**
Session จบด้วย open issue — มีปัญหาใหม่บน TikTok ที่ยังไม่ได้ investigate ถ้า context ถูก clear ไปก่อน session ถัดไปอาจต้อง re-read code ใหม่ทั้งหมด

## Lessons Learned

1. XPath ที่ดีที่สุดคือ XPath ที่จับ semantic text (span text, aria-label) ไม่ใช่ generated class names
2. ปุ่ม test แบบ isolated (Test Upload) ช่วยลด cycle time ในการ debug automation อย่างมาก
3. Flow order ใน automation ต้องตามหลัง UI จริง ไม่ใช่ตาม logic ที่ "น่าจะ" ถูก
