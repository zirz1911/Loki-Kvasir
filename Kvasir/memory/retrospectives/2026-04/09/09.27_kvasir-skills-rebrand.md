## Honest Feedback

**1. Python script สำหรับ bulk replace มีโอกาสผิดพลาดสูง** — ต้องเขียน protection cases ให้ครบ (`oraclenet.org`, MCP function names, ancestor repo URLs) ก่อน run จริง การ test ด้วย grep หลัง run ช่วยได้มาก

**2. Forgejo push ต้อง create repo ก่อนเสมอ** — ไม่มี "push to create" เหมือน GitHub ทำให้ต้องมี step เพิ่ม (curl API) ทุกครั้งที่มี repo ใหม่

**3. Skill `retrospective` เป็น alias ของ `wrap` แต่ description ยังพูดถึง `/rrr`** — ควร update ใน next session
