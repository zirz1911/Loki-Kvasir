## Honest Feedback

**Friction 1: `skipDangerousModePermissionPrompt` ใน settings.json**
ผมควรรู้ว่า key นี้มีผลต่อ Claude Code จริง ไม่ใช่แค่ config ที่ watcher อ่าน การ set ค่านี้โดยไม่ warn Lokkji ก่อนเป็นความประมาท แม้จะแก้ได้เร็ว แต่ไม่ควรเกิดขึ้น

**Friction 2: Tool ชื่อ "Task" vs "Agent"**
ควร inspect JSONL จริงก่อนเขียน code ที่ depend on tool name ชื่อเป็น implementation detail ที่ Claude Code สามารถเปลี่ยนได้ทุก version ควร verify ทุกครั้งที่ build feature ที่ parse JSONL

## Lessons Learned

1. **`~/.claude/settings.json` มี side effects จริงกับ Claude Code** — key อย่าง `skipDangerousModePermissionPrompt` เปลี่ยน behavior ของ Claude Code ทั้งหมด ไม่ใช่แค่ config ที่ third-party tools อ่าน ต้อง warn user ก่อนแก้ไฟล์นี้
2. **Timer-based detection ไม่สามารถแยก "waiting" vs "running" ได้** — JSONL ไม่บันทึก "user approved" event เลย การใช้ hooks ที่ fire ก่อน approval prompt เป็น only reliable solution
3. **Claude Code tool names เป็น implementation detail ที่เปลี่ยนได้** — ใน v2.1.63 subagent tool ชื่อ `"Agent"` ไม่ใช่ `"Task"` ต้อง verify จาก JSONL จริงทุกครั้ง อย่าสมมติจาก memory หรือ docs เก่า
4. **oracle-voice-tray push ได้แค่ `paji` remote** — `origin` คือ Soul-Brews-Studio org ที่ `zirz1911` ไม่มีสิทธิ์ push ห้าม push ไป origin เด็ดขาด
5. **PreToolUse hook architecture ดีกว่า JSONL polling สำหรับ approval** — hook fire ครั้งเดียว ตรงเวลา ไม่มี false positive จาก slow tools
