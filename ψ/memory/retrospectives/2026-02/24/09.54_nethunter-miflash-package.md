## Honest Feedback

**Friction 1**: ฉัน assume device name โดยไม่ verify — "Redmi Note 9 Pro" อยู่ใน retrospective ตั้งแต่ session 18.13 และฉันไม่ได้ตรวจสอบว่า codename `surya` map ไปที่ device ใดก่อน copy ข้อมูลนั้นมาใช้ ควรมี habit ของการ `fastboot getvar product` หรือ lookup codename table เมื่อพูดถึง device ใหม่

**Friction 2**: `flash_all_except_data.bat` ยังใช้ `adb shell twrp install` สำหรับ LOS zip ซึ่งจะ overwrite system/vendor ทั้งหมด แต่ไม่ได้ warn user ว่านี้ยังคงเป็น "system update" ที่อาจทำให้ app data บน system partition (ถ้ามี) หาย ชื่อ "except_data" อาจทำให้ user เข้าใจผิดว่า "ปลอดภัยทั้งหมด"

**Friction 3**: Package ยังไม่มี verification step — ไม่มี checksum verification ของ image files ก่อน flash ไม่มีการ verify ว่า `adb shell twrp install` สำเร็จจริงหรือแค่ exit 0 โดยที่ installation ล้มเหลวภายใน TWRP ควร parse TWRP output เพื่อ verify

## Lessons Learned

1. **`surya` = POCO X3 NFC ไม่ใช่ Redmi Note 9 Pro** — ตรวจ codename ก่อน assume ทุกครั้ง `fastboot getvar product` หรือ lookup ใน LineageOS device list
2. **LOS OTA zip format vs fastboot format**: LOS zip สำหรับ TWRP ประกอบด้วย `boot.img`, `dtbo.img`, `vbmeta*.img` โดยตรง แต่ system/vendor เป็น `.new.dat.br` + `.transfer.list` — ต้อง convert ด้วย brotli + sdat2img ถ้าต้องการ flash ผ่าน fastboot โดยตรง
3. **Miflash style package design**: แยก prepare (build images) กับ flash (deploy) ออกจากกัน ทำให้ re-flash ง่ายโดยไม่ต้อง re-extract ทุกครั้ง
