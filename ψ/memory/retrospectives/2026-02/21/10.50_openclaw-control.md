## Lessons Learned

1. **Verify CLI flags จาก `--help` ก่อนเขียน skill.** ทุกครั้งที่เขียน command ลงใน skill file ให้รัน `<tool> --help | grep <flag>` ก่อนเสมอ อย่า assume จาก pattern ของ tool อื่น

2. **`openclaw agent` ไม่ต้องการ token สำหรับ local loopback.** Gateway ที่ bind `127.0.0.1` ไม่มี auth สำหรับ local connections — token ใช้แค่ใน `openclaw acp` เมื่อเชื่อมจาก remote

3. **การส่งผ่าน tmux-send มี approval prompt เป็น blocker.** Claude Code sessions ที่ไม่ได้ตั้ง auto-approve จะ pause รอ input — ในสถาปัตยกรรมที่ต้องการ automation ต้องตั้ง allowed commands ล่วงหน้าใน session นั้น

4. **Two Loki instances สามารถทำงานร่วมกันได้.** Instance หนึ่งเป็น orchestrator, อีกอันเป็น executor — pattern นี้ scale ได้และ align กับ Principle 5 (Form and Formless)
