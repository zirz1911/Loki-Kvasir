## Lessons Learned

1. **git pull ก่อน panic** — เมื่อไฟล์หายจากเครื่อง ให้ตรวจ `git log --all -- <file>` ก่อนเสมอ ส่วนใหญ่ไฟล์อยู่ใน remote แล้ว แค่ยังไม่ได้ pull
2. **Statusline files location** — `.claude/statusline.py` (main) และ `.claude/statusline-command.sh` (legacy shell wrapper) อยู่ใน git ตั้งแต่ commit `802ed65`
3. **Setup guide ยังขาด** — การ link statusline ใน `.claude/settings.json` ยังไม่มีเอกสาร ควรเพิ่มใน onboarding doc
