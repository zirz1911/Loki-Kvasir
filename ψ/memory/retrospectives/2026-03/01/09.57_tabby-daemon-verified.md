## Lessons Learned

1. **Bash cwd resets to project root after every command** — ต้องใช้ absolute paths ทุกครั้งที่ทำงานใน repo อื่น การรัน `cd X && cmd` ใน single Bash call ไม่ช่วยเพราะ next call จะ reset อีก
2. **Retrospective gap เป็นไปได้ถ้า session สั้น** — เมื่อ /rrr ถูกรันตอน session ใหญ่ งานเล็กๆ ที่ทำในช่วงเวลาเดียวกัน (เช่น commit ที่ boundary ของ session) อาจไม่ถูกบันทึก ควร spot-check git log ตอน recap
3. **Daemon IPC protocol fully verified**: create/attach/input/output/kill/exit ทำงาน end-to-end บน Windows Named Pipe ด้วย node-pty exit code -1073741510 = `STATUS_CONTROL_C_EXIT` เป็น normal บน Windows kill
4. **test-attach.js เป็น regression reference** — ถ้า daemon เปลี่ยนใน future ไฟล์นี้เป็น quick smoke test ที่ verify ทุก command ใน protocol ภายใน 3 วินาที
