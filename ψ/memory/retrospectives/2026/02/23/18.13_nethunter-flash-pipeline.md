## Honest Feedback

**Friction 1**: VirtualBox NAT ทำให้ USB passthrough ขาดทุกครั้งที่ device เปลี่ยน mode — บังคับให้ต้องทำ fastboot operations บน Windows แทน Linux ทำให้ workflow ไม่ smooth

**Friction 2**: ไม่ได้คิดถึง kernel/vendor dependency ตอน downgrade LOS — ควร plan partition strategy ทั้งหมดก่อน flash แทนที่จะแก้ปัญหาเป็น layer ๆ

**Friction 3**: NetHunter zip ไม่สามารถ transfer จาก Linux VM → Windows ได้ง่าย (NAT network ไม่ expose port) — ต้องเขียน PowerShell fix แทน

## Lessons Learned

1. **Partition strategy ต้องวางแผนทั้งหมดก่อน** — boot, kernel, system, vendor ต้องมาจาก ROM version เดียวกัน การ mix LOS 22.2 boot กับ LOS 20 system ทำให้ WiFi/hardware ไม่ทำงาน เพราะ kernel driver กับ HAL ไม่ตรงกัน

2. **LOS zip flash ผ่าน TWRP จะ overwrite boot.img** — Magisk ที่ patch ใน boot.img จะหายทุกครั้งที่ flash ROM zip ใหม่ ต้อง flash Magisk หลัง ROM เสมอ

3. **NetHunter 2025.x ต้องติดตั้งผ่าน Magisk ไม่ใช่ TWRP** — installer script บอกชัดเจนใน log ถ้าอ่าน log ก่อนจะประหยัดเวลาได้มาก

4. **Android transfer list format**: `cmd count,start,end,...` — `count` คือ จำนวน endpoints ไม่ใช่ range เอง ต้อง skip ตัวแรก

5. **VirtualBox NAT + fastboot** — device ใช้ VID:PID ต่างกันใน ADB mode vs Fastboot mode VirtualBox ไม่ auto-recapture ต้องเพิ่ม USB filter สำหรับทั้ง 2 mode หรือย้ายไปใช้ Bridged/Host-only network

6. **`adb sideload` total xfer 0.10x** = installer script ตรวจสอบ version แล้ว reject เร็วมาก — ไม่ใช่ network error แต่คือ assertion ใน updater-script ล้มเหลว ต้องดู recovery.log เสมอ
