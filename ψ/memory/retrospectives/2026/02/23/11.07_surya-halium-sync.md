## Lessons Learned

1. **Verify external repo names before writing manifests.** GitHub API check is fast (`curl -s api.github.com/repos/ORG/REPO`). A 404 from `repo sync` costs more time than a quick verification upfront.

2. **Use Write tool for structured files, not heredoc.** When a file needs exact formatting (XML declarations, no leading spaces), the Write tool is reliable. Bash heredoc with multi-line indentation is fragile in interactive sessions.

3. **WSL2 USB ADB is a workaround — native Linux is the real path.** For Android development requiring ADB, native Linux eliminates the entire usbipd/Windows-ADB-server/device-mode problem class. Suggest migration earlier when WSL2 ADB fights back.

4. **Halium manifests don't include device-specific repos.** Always need a `.repo/local_manifests/<device>.xml` for device tree + kernel. This is expected, not a bug.

5. **usbipd BUSID changes when device reboots to different mode.** fastboot (18d1:d00d) and Android MTP (2717:0afe) have different BUSIDs. Always re-run `usbipd list` after mode change before attaching.
