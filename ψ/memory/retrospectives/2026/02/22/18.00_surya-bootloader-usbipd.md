## Lessons Learned

1. **Verify prerequisite existence before debugging behavior.** When troubleshooting a tool chain (A → B → C), confirm each layer actually exists before diagnosing why C isn't working. "Not installed" and "installed but misconfigured" have identical downstream symptoms.

2. **First WSL USB check should always be from Windows side.** `usbipd list` STATE column is ground truth. If STATE isn't `Attached`, nothing in WSL will work regardless of what's installed there.

3. **Bootloader unlock is a real milestone.** It's irreversible, requires correct mode, carries brick risk. When it's done cleanly, acknowledge it — it means the user has real device access and confidence.
