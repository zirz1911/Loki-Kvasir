2. **Openclaw agent ต้องการ chatId (ตัวเลข) ไม่ใช่ชื่อ** สำหรับ Telegram target Lokkji's chatId: `8190607091` — บันทึกไว้ใน skill config

3. **ตรวจสอบ pane state ก่อนส่ง tmux command** ถ้า claude30 กำลัง busy หรือมี approval prompt อยู่ command ที่ส่งเข้าไปจะ fail หรือ corrupt state

4. **End-to-end loop สำเร็จ**: Loki Oracle → tmux-send → claude30 → openclaw agent → ws://127.0.0.1:18789 → Telegram `@conclaw30bot` → chatId 8190607091
