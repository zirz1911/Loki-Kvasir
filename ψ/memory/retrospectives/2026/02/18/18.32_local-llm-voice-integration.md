## Honest Feedback

**1. Friction: Timeout ที่ 120s ไม่พอสำหรับ 32B model**
ต้อง fail → debug → แก้ → restart สองรอบ ควรตั้ง timeout ไว้ที่ 300s ตั้งแต่แรกสำหรับ large model ถ้ารู้ว่า model ใหญ่

**2. Friction: `$` variable interpolation ใน PowerShell ผ่าน Bash**
ตลอด session ต้องหาวิธีรัน PowerShell command ที่มี `$` variables — บางครั้ง bash interpolate ทิ้งก่อนส่งไป PowerShell ทำให้ต้อง escape หรือเขียน script ผ่าน Python แทน ควรมี pattern ที่ชัดกว่านี้

**3. Friction: Path spaces (D:\Paji AI\)**
Directory ชื่อ "Paji AI" มี space ทำให้ PowerShell command หลายตัว fail ต้องใช้ single quote หรือ escaped path ซ้ำๆ เป็น friction เล็กน้อยที่สะสม

**ที่ทำได้ดี**: อ่าน source ก่อนแก้เสมอ ไม่ได้ guess code ที่ไม่รู้จัก `speak_text()` function ง่ายมากเพราะอ่านจริงก่อน adapt

## Lessons Learned

**Pattern**: อ่าน doc ในห้องก่อนแนะนำ external solution
- Lokkji เขียน `CLAUDE_CODE_WITH_LOCAL_LLM.md` ไว้แล้วอธิบายทุกอย่าง ถ้าไม่ตรวจ Paji repo จะเสียเวลา propose LiteLLM approach ที่ doc บอกชัดว่าไม่แนะนำ

**Pattern**: Rust `#[cfg(target_os)]` สำหรับ cross-platform ที่ elegant
- ไม่ต้อง runtime check, ไม่ต้อง if/else, compile-time ตาม platform

**Anti-pattern**: timeout default ต่ำเกินไปสำหรับ local LLM model ขนาดใหญ่
- 120s ไม่พอสำหรับ 32B model บน consumer hardware, ใช้ 300s เป็น baseline
