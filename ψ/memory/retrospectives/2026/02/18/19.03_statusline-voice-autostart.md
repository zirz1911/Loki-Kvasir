## Honest Feedback

**1. Friction: jq ไม่ติดตั้งบน Windows — ควรรู้ล่วงหน้า**
Windows environment ไม่มี jq by default ควร verify dependencies ก่อน generate script ใดๆ ที่ใช้ Unix tools นอก core bash

**2. Friction: exit code 1 จาก bash tool ทำให้ debug ยาก**
ตลอด session ไม่แน่ใจว่า script จริงๆ exit 0 หรือ 1 เพราะ bash tool รายงาน exit 1 แม้ output ถูก การทดสอบด้วย `echo "EXIT:$?"` ก็ไม่ได้ผลที่น่าเชื่อถือ ต้องใช้ "output correct = probably fine" เป็น heuristic

**3. Friction: StatusLine command ใน settings.local.json ต้องใช้ path ที่ถูกต้อง**
ต้องลอง backslash vs forward slash กว่าจะหา format ที่ Claude Code รับได้ ควร document ไว้ว่า Windows path ใน JSON settings ต้องใช้ forward slash

## Lessons Learned

**Pattern**: Windows environment — use Python, not bash/Unix tools
- jq, sed, awk ไม่มีบน Windows Git Bash by default ถ้าต้องการ JSON parsing ให้ใช้ Python แทน

**Pattern**: Windows stdout encoding ต้อง reconfigure ก่อน print Unicode
```python
sys.stdout.reconfigure(encoding="utf-8")
```
ใส่ทันทีหลัง import ก่อน print ใดๆ ที่มี Unicode characters

**Pattern**: Claude Code statusline fields ที่มีประโยชน์
- `cost.total_cost_usd` — ค่าใช้จ่าย session
- `context_window.total_input_tokens + total_output_tokens` — tokens รวม
- `agent.name` — agent ที่ active อยู่ (empty = Odin/main)
